❓ Aide & Guide de l'application

Tout comprendre et résoudre les problèmes courants
📋 Fonctionnalités principales
  • Dashboard — vue d'ensemble : ventes, commandes, plats, messages non lus.
  • Discussions — chat en direct avec les clients (réponses rapides disponibles).
  • Commandes — recevoir, changer le statut, marquer payé, imprimer le reçu.
  • Menu (Plats) — ajouter/modifier/supprimer un plat, changer son prix et sa photo.
  • Catégories — organiser le menu.
  • Statistiques — chiffre d'affaires, commandes livrées, plats les plus vendus (calculés automatiquement).
  • Promotions — créer une réduction (% ou montant) avec dates.
  • Paramètres — restaurant, plats, livraison, paiement, apparence, sécurité, configuration.
🛠️ Solutions aux problèmes courants
  • Je ne reçois pas les commandes → vérifiez que le restaurant est Ouvert (bouton en haut du Dashboard) et que la livraison est activée (Paramètres → Livraison).
  • Un client ne voit pas un plat → dans Menu (Plats), vérifiez que le plat est Disponible.
  • Le chat ne répond pas → le client et vous devez être connectés. Vérifiez votre connexion internet.
  • J'ai oublié mon code PIN → le PIN par défaut est 1234. Vous pouvez le changer (Paramètres → Sécurité).
  • J'ai oublié mon identifiant gérante → l'identifiant par défaut est cheffe. Vous pouvez le changer (Paramètres → Sécurité).
  • Le client ne trouve pas l'admin → normal ! L'admin est caché : il se connecte avec l'identifiant cheffe + PIN sur la page de connexion normale.
  • La livraison doit être payante → Paramètres → Livraison : désactivez la gratuité et mettez un montant de frais.
  • Changer le prix d'un plat → Menu (Plats) → Modifier → changez le prix.
